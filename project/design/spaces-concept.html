Why this design: Spaces

Every room is a shared space, so it opens as a board of tiles instead of one long chat: Files, People, Apps, Chat and Transfers, all visible at once. You never leave the room to check on a download, see who has a seat, or open a shared app. Any tile can grow to full screen when you need to focus, and shrink back. The orange and navy come straight from Polyphron: orange is for actions and anything live, navy anchors every header and code. Empty seats show the room code so inviting is one tap. On a phone the same tiles become the five tabs at the bottom, in the same order, so nothing has to be learned twice.
