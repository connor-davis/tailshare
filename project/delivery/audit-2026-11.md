# Audit, November 2026

Two read-only audits ran on 2026-11-21 against `develop` at `8cf5cbb`: one of the
Go sidecar (Sonnet 5.5) and one of the desktop app (GPT 6.1 Sol). The Orchestrator
reviewed both reports and every fix. All findings were judged real and fixed in
PR `connor_davis/audit-fixes`. Each fix has a regression test.

## Go sidecar (22 findings)

| ID | Severity | Finding | Fix | Test |
|----|----------|---------|-----|------|
| B1 | high | Any member could grow memory without limit with huge `transfer.offer` paths; refused jobs were kept | Path cap (4096 bytes, 255 per element) in `share.Localize`; refused offers are not kept; history bounded | `TestAuditPathLengths`, `TestAuditRefusedOffersNotRetained`, `TestAuditHistoryBounded` |
| B2 | medium | Chat attachment name and path had no length limit | Limits in `peer/chat.go` | `TestAuditOversizedAttachmentRefused` |
| B3 | medium | One silent stream stalled every new mesh stream (head-of-line in `Accept`) | Prefix read per stream, off the accept loop | `TestAuditSilentPrefixDoesNotBlockAccept` |
| B4 | medium | Unlimited half-open control streams per member; frame buffer allocated up front | Bounded pending controls; frames grow as bytes arrive | `TestAuditPendingControlsBounded`, `TestAuditFrameAllocatedIncrementally` |
| B5 | medium | Any member could hold both transfer slots of a manager attached to someone else | Transfer methods answer only the attached member; offers rate-limited | `TestAuditUnattachedConversationDenied`, `TestAuditOfferRateLimited` |
| B6 | medium | Uploads had no free-space check and partials were kept forever | Free space minus reserve; partial quota; 7-day pruning on room open; failed upload removes its partial | `TestAuditUploadFreeSpace`, `TestAuditPartialQuota`, `TestAuditPruneOldPartials`, `TestAuditSenderFailureRemovesUploadPartial` |
| B7 | medium | Join stream flood and Allow-prompt spam | At most 4 join streams; back-off after Deny; key fingerprint on the prompt | `TestAuditJoinStreamsBounded`, `TestAuditDenyBackoffAndFingerprint` |
| B8 | medium | One bad member blocked all future joins and could not be removed | A member that refuses `share.admit` is dropped; host `DELETE /api/session/members/:id` | `TestAuditRejectingMemberDoesNotBlockJoin`, `TestAuditRemoveMemberAuthority`, `TestAuditRemoveMemberRoute` |
| B9 | medium | A verified download was deleted when the folder could not hard-link | Partial kept on commit error; rename fallback after an exclusive check | `TestAuditCommitWithoutHardLinks` |
| B10 | medium | Hashing ignored cancellation, so Leave and Cancel could hang for minutes | Hashing checks the context every 1 MiB | `TestAuditHashCancellation`, `TestAuditCancelWhileHashing` |
| B11 | medium | Downloads that took over 30 s to hash could never start | Offer time limit no longer covers the responder's hashing | `TestAuditLargeDownloadOfferTimeout` |
| B12 | low | Live chat stopped silently after a burst | Subscription recovers | `TestAuditChatSubscriptionRecovers` |
| B13 | low | Names with `..` inside them could not be downloaded | Only whole `..` elements are refused | `TestAuditDoubleDotDestinationAccepted` |
| B14 | low | A long non-ASCII computer name broke hello | Truncate by rune | `TestAuditNonASCIIHostnameTruncation` |
| B15 | low | Some Go error text could reach the screen | Transport errors mapped to plain sentences | `TestAuditTransportErrorsStayPrivate` |
| B16 | low | Download roots were never released | Roots deduplicated and released | `TestAuditDownloadRootsDeduplicated` |
| B17 | low | `TAILSHARE_MAIN_TOKEN` was not validated | Same 32-byte check as the API token | `TestAuditMainTokenValidation` |
| B18 | low | Allow stopped the unused-code expiry even when the join failed | Expiry restarts | `TestAuditAllowedUnlinkedCodeStillExpires` |
| B19 | low | Windows 8.3 short names could reach a hidden partial | 8.3 aliases refused (long names with `~2` still allowed) | `TestAuditShortAliasRefused`, `TestAuditActualShortPartialAlias` |
| B20 | low | Another member could resume or delete someone's partial | Partial records owner, hash and size | `TestAuditPartialIdentity`, `TestAuditOtherOwnerOfferRefused` |
| B21 | low | `list` re-read whole folders on every page request | Short listing cache | `TestAuditListingReadOnce` |
| B22 | low | Display name was the only identity shown | `fingerprint` on members and pending joins; duplicate names get a suffix | `TestAuditDuplicateNameGetsFingerprint` |

## Desktop app (9 findings)

| ID | Kind | Severity | Finding | Fix |
|----|------|----------|---------|-----|
| F1 | bug | high | A join link opened with the app closed was lost | Held until session state is known, then joined once |
| F2 | bug | high | A missing downloads folder stopped the engine starting | Health no longer depends on the folder; the UI says "Choose another folder" and Download is off until fixed |
| F3 | bug | medium | Late HTTP replies overwrote newer live state | Live socket owns state after its first snapshot; chat history merges |
| F4 | security | medium | Renderer chat grew without limit | 200-message cap on every path |
| F5 | ux | medium | Hiding Members hid join requests | Badge on the toggle and a spoken announcement |
| F6 | bug | medium | A slow send erased what you typed next | Draft cleared only if unchanged |
| F7 | bug | medium | Reloading lost the room code and folder controls | Main keeps the current room |
| F8 | ux | medium | Panels did not fit at the minimum window size | Minimum 800x600; transfer rows wrap |
| F9 | ux | low | Open folder and Forget failed silently | Plain-sentence inline errors |

## Orchestrator review notes

- The first B19 fix refused every name containing `~` and a digit (for example
  `report~2024.pdf`). Narrowed to real 8.3 shapes, with a test for long names.
- UI parts of B8 (remove button) and B22 (fingerprint display) land in the UI
  polish PR.

## Not covered

- Race detector: no C compiler on the build PC.
- Rendered layout and contrast: checked in the UI polish PR with light and dark
  screenshots.
